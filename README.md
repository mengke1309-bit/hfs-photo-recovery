# HFS+ 移动硬盘照片恢复工具

> Windows 下的照片文件雕刻（File Carving）恢复工具。专为「Mac 格式（HFS+）移动硬盘在 Windows 上读不了、照片又被误删了」这个尴尬场景而生。

## 它解决什么问题

- 移动硬盘是 Mac 的 **HFS+** 格式，Windows 原生不认，更别提误删后恢复了；
- 照片被误删 / 格式化 / 文件系统损坏，普通恢复软件按文件系统找目录结构，此时已经无目录可找。

本工具不去理解文件系统——**直接把硬盘当成一长串原始字节，从头到尾按照片的二进制签名把文件抠出来**。被删的文件只是「门牌号」被撕了，「房子」（数据）还在，所以能找回来。HFS+ / exFAT / NTFS 盘均可扫。

## 支持的格式

| 类别 | 格式 |
| --- | --- |
| 通用照片 | JPEG（过滤 < 100KB 的缩略图/内嵌预览，避免大量垃圾小图） |
| 索尼 | ARW |
| 尼康 | NEF |
| 佳能 | CR2 / CR3（走查 ISO BMFF 盒结构定长，并提取内嵌预览） |
| 奥林巴斯 | ORF |
| 松下 | RW2 |
| 宾得 | PEF |
| 富士 | RAF |
| 通用 RAW | DNG |

## 功能特性

- **两段式流程**：扫描（只读）→ 清单 + 缩略图预览 → 勾选 → 只恢复你选中的文件；
- **全程只读**：源盘一个字节都不写，恢复目标目录强制校验不得在源盘上；
- **Apple 风格 tkinter UI**，无需安装任何 GUI 框架；
- 后台线程扫描，界面不卡，带圆角进度条和实时日志；
- **坏块抢救**：按 1MB 粒度跳过物理坏块继续扫，不因个别坏道中断；
- 自动请求管理员权限（`\\.\PhysicalDrive` 原始读盘需要）。

## 使用方法

### 方式一：直接下载打包好的 exe（推荐）

到本仓库的 **[Releases](../../releases)** 页面下载 `HFS照片恢复工具_修复版.exe`，右键**以管理员身份运行**。

> Windows SmartScreen 可能提示未知发布者——点「仍要运行」即可（个人工具没有代码签名证书）。

### 方式二：从源码运行

```bash
# 需要 python.org 官方版 Python 3.x，以及 Pillow（可选，用于缩略图预览）
py -3 HFS照片恢复工具.py
```

- 无 Pillow 也能扫和恢复，只是没有预览图；
- 需要**管理员权限**（程序内可点击「获取权限」自动提权重启）。

### 打包 exe（可选）

```bash
pip install pillow pyinstaller
pyinstaller --onefile --uac-admin HFS照片恢复工具.py
```

## ⚠️ 重要须知（免责声明）

- 本工具**只读扫描、按需恢复**，但不能替代专业数据恢复服务；
- **数据无价，恢复前请勿再往源盘写入任何数据**——新数据会覆盖待恢复的扇区；
- 恢复结果取决于数据是否已被物理覆盖，碎片化严重的文件可能恢复不全；
- 重要数据请养成多地备份的习惯。使用本工具产生的任何后果由使用者自行承担。
